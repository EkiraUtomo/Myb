Permanent execution loader

The loader is a bearer capability. It stays valid until you regenerate, disable, delete, or expire the script.

Storage

One script = one encrypted file: locker/scripts/<slug>.json. Large Lua payloads therefore don't grow one shared scripts.json file.

The source is still delivered to an authorized execution client. Server-side encryption protects storage and unauthorized access, but cannot make client-received code impossible to observe.
