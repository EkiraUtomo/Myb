ZUMHUB / LOCKER ADMIN

Script vault

Encrypted at rest, server-authorized delivery, short-lived signed run URLs. The browser never receives the master secret.

Security model

Source is encrypted with AES-256-GCM before being committed to the GitHub-backed vault. Delivery uses HMAC-signed, 90-second tokens. GitHub and locker secrets are environment variables on Vercel; they are not placed in this page or repository.
