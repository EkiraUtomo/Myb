ZUMHUB / LOCKER ADMIN

Script vault

Private admin session. Scripts are encrypted at rest. Public execution uses a permanent per-script capability URL unless you revoke, regenerate, disable, or expire it.

Admin authentication

Sign in with the admin secret configured in Vercel. A signed HttpOnly session cookie is issued after successful authentication.

Permanent execution loader

This URL is a bearer capability. Anyone who gets the complete loader can request the script. It does not expire by itself. Regenerate the key to invalidate the old loader.

What the locker actually protects

Source is encrypted with AES-256-GCM before being committed to the GitHub-backed vault. The execution endpoint requires a 256-bit random capability key whose hash is stored in the vault. The source is decrypted only on the server when that capability is presented.

No client-side locker can make code impossible to intercept: Roblox must receive the source to execute it. This design protects storage and unauthorized access; it cannot prevent a hostile execution environment from observing or modifying the returned code.
